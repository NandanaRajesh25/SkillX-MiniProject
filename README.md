# SkillX

**SkillX** is a platform where users can exchange skills - find people to learn from, and teach others what they know.

## 🚀 Features

- User authentication
- Profile creation and editing
- Post and view **skill requests**
- Automatic skill matching (Damerau-Levenshtein distance)
- **Chat interface** with file uploads
- Dashboard for managing matches
